# Employee Management System

## Project Description
This is a simple Employee Management System developed using PHP and MySQL.

## Features
- Admin Login
- Dashboard
- Add Employee
- Employee List
- Search Employee
- Edit Employee
- Delete Employee
- Photo Upload

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Database
Import the `employee_management.sql` file into phpMyAdmin.
